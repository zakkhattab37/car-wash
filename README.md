# مغسلة البشمهندس

نظام إدارة مغسلة سيارات باللغة العربية وبتخطيط من اليمين إلى اليسار. يعمل محلياً ويحتفظ بسجلات العرض والتعديلات في مساحة التخزين الخاصة بالمتصفح.

## التشغيل المحلي

١. افتح الطرفية داخل مجلد المشروع. يتطلب الأمر توفر Node.js 18 أو أحدث.
٢. شغّل `node server.mjs`.
٣. افتح [النظام المحلي](http://127.0.0.1:4173). لإيقاف الخادم، اضغط Ctrl+C.

يمكن استخدام أي خادم ملفات ثابت بديل. افتح التطبيق من عنوان الخادم كي تتمكن وحدات JavaScript من العمل. استخدم العنوان والمنفذ نفسيهما عند العودة إلى سجلاتك.

## تجربة دورة غسيل

١. اختر **تسجيل غسلة جديدة** من لوحة التحكم.
٢. ابحث عن عميل أو سجله سريعاً، ثم اختر إحدى سياراته أو أضف سيارة.
٣. اختر الخدمات والموظف وعدّل كميات الاستهلاك والخصم وطريقة الدفع.
٤. سجّل الطلب ثم تابع جاهزية السيارة أو أكمل الطلب مباشرة. أدخل الدفعة بالكامل أو جزءاً منها أو صفراً.
٥. اطبع الإيصال من تفاصيل الطلب. راجع حركة الاستهلاك في **المخزون** والتحصيل في **الخزينة**.
٦. استخدم **التقارير** للطباعة أو تصدير CSV، وقائمة الحساب لتجربة أدوار الكاشير والمخزون ومدير النظام.

## قواعد التشغيل

- يتأكد النظام من وجود المخزون قبل إكمال الطلب ويحوّل اللتر والمللي لتر والكيلو جرام والجرام تلقائياً.
- يُسجل دفع الغسيل واسترداده وفق وسيلة الدفع. يحسب الرصيد المادي من الحركات النقدية، ويعرض المدفوعات الإلكترونية على حدة.
- تعمل حركة شراء المواد على زيادة المخزون وتسجيل المصروف. تُستخدم تكلفة استهلاك المواد في تقدير الربحية.
- يرد إلغاء الطلب المكتمل صافي المقبوضات لكل وسيلة دفع. يمكن إرجاع المواد فعلياً عند التأكيد.
- تغطي أدوار العرض التنقل والإجراءات في هذه الواجهة المحلية. البيانات تجريبية وتُخزن في المتصفح. يحتوي العرض على أرقام هواتف تجريبية ومعرّفات قومية مقنّعة.
- يمكن استعادة سجلات العرض من **الإعدادات**. تمحو الاستعادة التعديلات الحالية بعد التأكيد.
- تعمل الواجهة والرسوم التفاعلية محلياً. يتضمن مجلد `assets` خط Cairo العربي من Google Fonts وأيقونات Flaticon وحزمة التحليلات المبنية.

## تطوير حزمة التحليلات

تستخدم رسوم لوحة التحكم مكوّن Chart من shadcn/ui مع Recharts، وحركات الدخول من Framer Motion. بعد تعديل ملفات التحليلات، شغّل `npm ci` مرة لتثبيت الاعتمادات ثم `npm run build` لتحديث `assets/analytics.js`.

## الاختبارات

بعد تثبيت الاعتمادات عبر `npm ci` باستخدام Node.js 22 أو أحدث، شغّل `npm test` لاختبار قواعد العمل ومسارات الاستخدام في المتصفح. يمكن تشغيل `npm run test:unit` أو `npm run test:browser` بشكل مستقل.

تشغّل اختبارات المتصفح خادماً مؤقتاً ببيانات عرض معزولة. تستخدم Microsoft Edge على ويندوز، وChromium على الأنظمة الأخرى. لتثبيت Chromium على الأنظمة الأخرى، شغّل `npx playwright install chromium`.
